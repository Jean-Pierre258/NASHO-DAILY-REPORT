Guhuza Urubuga na Google Sheet yawe

Huza iyi fomu na Google Sheet yawe kugira ngo buri raporo ijye yikora muri sheet ako kanya!

Google Sheet ntiyari yahuzwa

Shyiramo Webhook URL ya Google Apps Script ikurikira.

Shyiramo URL y'ingenzi wavanye muri "Deploy as Web App" muri Google Sheet yawe.
Iyi link izajya ifunguka iyo ukanze "Reba muri Google Sheet".
Amabwiriza y'uburyo bwo kubona iyi Link muri Google Sheet yawe (Mu masegonda 30)
  1. Fungura Google Sheet yawe usanzwe ukoresha muri browser.
  2. Kanda ahanditse Extensions hejuru > hitamo Apps Script.
  3. Siba ibyanditsemo byose maze ushyiremo iyi code ikurikira (Kanda "Copy Code"):
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Niba ari ubwa mbere, shyiraho imitwe y'inkingi (Headers)
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "ID", "Itariki", "Igihe (Shift)", "Utanga Raporo", "Telefone",
        "Ishami (Dept)", "Ahakorewe (Zone)", "Abakozi", "Amasaha",
        "Mazutu (L)", "Umusaruro", "Ibikorwa Byakozwe", "Imbogamizi",
        "Gahunda y'Ejo", "Icyitonderwa", "Yatanzwe Kuwa"
      ]);
    }

    // Ongeraho amakuru ya raporo nshya
    sheet.appendRow([
      data.id,
      data.date,
      data.shift,
      data.reporterName,
      data.reporterPhone || "",
      data.department,
      data.siteZone,
      data.metricWorkers,
      data.metricHours,
      data.metricFuel,
      data.metricProduction || "",
      data.tasksSummary,
      data.issuesSummary,
      data.tomorrowPlan,
      data.generalRemarks || "",
      data.submittedAt
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ "status": "success", "message": "Raporo yakiriwe neza muri Google Sheet!" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Kanda Deploy (iburyo hejuru mu ibara ry'ubururu) > New deployment.
  2. Kanda ku kazu k'uruziga (Gear icon) > Hitamo Web app.
  3. Ahanditse Execute as: hitamo Me.
  4. Ahanditse Who has access: hitamo Anyone (bityo form ishobore koherezamo amakuru).
  5. Kanda Deploy > Koporora Web app URL maze uyizane hano uyishyire muri ako kazu hejuru!
